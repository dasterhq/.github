# DASTER

DASTER is a developer cloud. One account gives you app hosting, PostgreSQL databases, app and marketing email from your own domain, domains and DNS, and AI tools over MCP.

You connect once from your terminal, IDE or AI agent, and each service is set up for you.

**Status:** opening soon. Join the waitlist at [daster.io](https://daster.io).

## Get started

- Website: [daster.io](https://daster.io)
- Docs: [daster.io/docs](https://daster.io/docs/)
- Guides: [daster.io/guides](https://daster.io/guides/)
- CLI on npm: [`@dasterhq/daster`](https://www.npmjs.com/package/@dasterhq/daster)
- CLI on PyPI: [`daster`](https://pypi.org/project/daster/)

```bash
npx @dasterhq/daster --help
# or
pip install daster
```
